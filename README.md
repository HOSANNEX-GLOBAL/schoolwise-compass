# School Compass

quero um front que atenda os item abaixo pra uma plataforma de gestao escolar:

Objetivo do Projeto Desenvolver uma plataforma web que permita: • Gestão de alunos; • Gestão de turmas; • Gestão de disciplinas; • Gestão de professores; • Lançamento e gestão de notas; • Gestão de recursos; • Emissão de documentos escolares; • Estatísticas e relatórios académicos; • Automatização dos processos escolares. Escopo Funcional Gestão Académica • Gestão de alunos; • Gestão de turmas; • Gestão de disciplinas; • Gestão de professores; • Gestão do ano letivo. Avaliações • Lançamento de notas; • Cálculo automático de médias; • Gestão de recursos; • Histórico de alterações. Documentos • Certificados; • Declarações; • Boletins; • Mini pautas; • Pautas trimestrais; • Pautas finais. Estatísticas • Aprovação e reprovação; • Desempenho por turma; • Desempenho por disciplina; • Relatórios académicos.
